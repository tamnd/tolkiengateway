The **image policy** of [Tolkien Gateway](../../main/T/Tolkien_Gateway.md) provides guidelines on what images should and shouldn't be uploaded to this wiki as well as guidance which should be followed when doing so.

As the world's largest Tolkien encyclopedia, Tolkien Gateway aims to have a comprehensive catalogue of visual representations of [Tolkien](../../main/J/J.R.R._Tolkien.md)'s works as well as other relevant images of from Tolkien [fandom](../../main/T/Tolkien_fandom.md) and scholarship. We include [photographs of notable individuals](<../../category/I/Images_of_people_(real-life).md>) as well as images of [publications](../../category/I/Images_of_publications.md) and [adaptations](../../category/I/Images_from_adaptations.md). These images are to be used to illustrate our articles as well as educating the reading about the representation of Tolkien's works.

## Naming conventions {#Naming_conventions}

Tolkien Gateway has a number of naming conventions that must be followed:

- **For artistic works** - including photos - the format is always *Copyright holder - Title of image*. If the image is untitled an appropriate description can be used instead. Examples include:
    - [File:Ted Nasmith - Eärendil Searches Tirion.jpg](../../file/T/Ted_Nasmith_-_Eärendil_Searches_Tirion.jpg.md)
    - [File:NOLANOS - Helcaraxe.jpg](../../file/N/NOLANOS_-_Helcaraxe.jpg.md)
    - [File:Tim Kirk - Gandalf and Bilbo.jpg](../../file/T/Tim_Kirk_-_Gandalf_and_Bilbo.jpg.md)

- **For images from adaptations** - films, video games, TV shows, card games etc - the format is always *Name of adaptation - Description of image*. The name of the adaptation is the same as both the title used for the Tolkien Gateway article. Examples include:
    - [File:The Hobbit (1977 film) - Bifur.png](<../../file/T/The_Hobbit_(1977_film)_-_Bifur.png.md>)
    - [File:The Lord of the Rings - The Fellowship of the Ring - Balin's Tomb2.jpg](../../file/T/The_Lord_of_the_Rings_-_The_Fellowship_of_the_Ring_-_Balin's_Tomb2.jpg.md)
    - [File:Born of Hope - Arathorn.jpg](../../file/B/Born_of_Hope_-_Arathorn.jpg.md)
    - [File:The Rings of Power (TV series) - Two Trees of Valinor.png](<../../file/T/The_Rings_of_Power_(TV_series)_-_Two_Trees_of_Valinor.png.md>)

- **For photographs of real people** simply use *Name of person*. Examples include:
    - [File:Peter Jackson.jpg](../../file/P/Peter_Jackson.jpg.md)
    - [File:Pauline Baynes.jpg](../../file/P/Pauline_Baynes.jpg.md)
    - [File:Elijah Wood.jpg](../../file/E/Elijah_Wood.jpg.md)

If there are two images which qualify for the same title use some other description of appropriate distinguisher taking into account the conventions above (usually a number). Examples include: [File:J.R.R. Tolkien - 1911.jpg](../../file/J/J.R.R._Tolkien_-_1911.jpg.md), [File:Jef Murray - Gandalf (Sketch 2).jpg](<../../file/J/Jef_Murray_-_Gandalf_(Sketch_2).jpg.md>) and [File:The Lord of the Rings - The Fellowship of the Ring - Elrond2.jpg](../../file/T/The_Lord_of_the_Rings_-_The_Fellowship_of_the_Ring_-_Elrond2.jpg.md).

Ampersands (&amp;) must not be used in file names, however diacritics are allowed, for example [File:Janka Latečková - King Aragorn.jpg](../../file/J/Janka_Latečková_-_King_Aragorn.jpg.md).

**Note:** All images are uploaded to the File namespace and, therefore, all have the prefix "File:".

## Image quality {#Image_quality}

Images of sizes up to 20MB can be uploaded to Tolkien Gateway. We favour the very highest quality images and strongly discourage users from resizing images themselves (as this can limit their future usefulness).

Similarly, all images should be cropped to remove unnecessary backgrounds. This includes removing <a class="extiw" href="http://en.wikipedia.org/wiki/Letterboxing_(filming)" title="wikipedia:Letterboxing (filming)">letterboxing</a> on film images.

## File types {#File_types}

Tolkien Gateway has a number of supported file formats:

- **Images** - .png, .jpg, .jpeg, .svg. Note that we no longer support .gif.
- **Audio** - .mp3, .ogg, .wav.

If you require additional file formats, please contact either [Mith](https://tolkiengateway.net/wiki/User_talk:Mith) or [Hyarion](https://tolkiengateway.net/wiki/User_talk:Hyarion).

## Deletion of images {#Deletion_of_images}

<dl><dd><i>See also: <a href="../D/Deletion_policy.md" title="Tolkien Gateway:Deletion policy">Tolkien Gateway:Deletion policy</a></i></dd></dl>

Images will deleted by [an administrator](../A/Administrators.md) without discussion under the following circumstances:

- **Irrelevance** - not Tolkien-related or related to the functioning of this wiki.
- **Duplication** - if there are two images exactly the same (or similar without sufficient justification and usage).
- **Supersession** - if another image is uploaded which makes an existing image redundant (such as one of a higher quality or an updated version).
- **Slash and nudity** - removed if overly gratuitous or seen as unnecessary. Appropriate nudity is permitted (for example [File:Ted Nasmith - Saeros' Fatal Leap 2.jpg](../../file/T/Ted_Nasmith_-_Saeros'_Fatal_Leap_2.jpg.md)).
- **Copyright violation** - an image without permission, and even without an appropriate copyright template, will be deleted.
- **Author request** - where an author/uploader revokes previously-granted permission.
- **Not fair use** - if an image uploaded with a fair use rationale is judged by an administrator to fall outside the bounds of fair use, it will be deleted.
