<td>#2

<td><a href="/wiki/User:KingAragorn" title="User:KingAragorn">KingAragorn</a>
</td>
<td>Discussion of what should be done to improve <a href="/wiki/Bilbo_Baggins" title="Bilbo Baggins">Bilbo Baggins</a>.
</td>
<td>It was agreed that the article should include the following headers: Appearance, Personality, History (broken down appropriately), Etymology, Other names, Genealogy, and Portrayal in adaptations (broken down appropriately).
</td></tr>
<tr style="font-size:100%; text-align: center; background-color:#E4F2D9;">
<td>#3
</td>
<td><a href="/wiki/User:Amroth" title="User:Amroth">Amroth</a>
</td>
<td>This is not meant against anyone, but if I lookto <a class="external text" href="http://www.tolkiengateway.net/w/index.php?title=The_Hobbit&amp;action=historysubmit&amp;diff=186924&amp;oldid=185158" rel="noreferrer noopener" target="_blank">the changes</a> made to <a href="/wiki/The_Hobbit" title="The Hobbit">The Hobbit</a> this month, we haven&#39;t made any improvement on it. It&#39;s still a copy of Wikipedia. Although, some section of <a href="/wiki/Sauron" title="Sauron">Sauron</a> and <a href="/wiki/Gandalf" title="Gandalf">Gandalf</a> have been improved most of the article haven&#39;t. If the same happens with the next article, <a href="/wiki/Bilbo_Baggins" title="Bilbo Baggins">Bilbo Baggins</a>, I fear the Countown will not work as hoped. How can we stimulate people to edit more on the &#34;Countdown&#34;-articles?
</td>
<td>Little was suggested on how to remedy the problem, but it was agreed that comments should be given on how to improve the articles.
</td></tr>
