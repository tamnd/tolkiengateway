**Tolkien Gateway:Updates** features updates and news specific to Tolkien Gateway.

## Site Updates {#Site_Updates}

### 2024 {#2024}

- **29-11-2024** - Short URL's can now be created for any article by selecting the three dots in the corner and choosing "Get shortened URL"
- **24-6-2024** - When editing an article, an automatic draft is now saved. You can close your browser and re-open it without losing your work.
- **9-6-2024** - We have upgraded to the latest version of MediaWiki, 1.41.
- **3-6-2024** - Editors can now click a "Preview" button in the top right when using "Edit source". This will show a preview of your changes next to the code.
- **3-6-2024** - You may have noticed we have made some minor tweaks to our theme. We will be spending the next several months updating various templates with more design surprises in store. Stay tuned!

<br>

### 2023 {#2023}

- **24-6-23** - We have configured a <a class="external text" href="https://maps.extension.wiki/wiki/Maps_for_MediaWiki" rel="noreferrer noopener" target="_blank">Maps</a> extension into TG so we can now incorporate both real-world as well as legendarium-based maps into articles.
- **19-6-23** - Hovering over a reference number in an article will now display a preview of the citation.
- **1-6-23** - Talk pages have been modernized to support a much more friendly interface both for new topics and replies. You will also now receive a notification if someone replies to your comment.
- **28-5-23** - You can now Thank individuals for their edit, the thank button is visible on the History tab of the respective article to the far right of their edit. A log of all "Thanks" events can be accessed via [Special:Log/thanks](https://tolkiengateway.net/wiki/Special:Log/thanks)
- **24-5-23** - When hovering over links on a computer, a thumbnail image and brief description will now appear without having to click on the link.
- **24-5-23** - Enabled wiki-syntax highlighting that can be toggled using the highlighter button in the edit toolbar.
- **21-5-23** - Our "favicon" in web browsers was updated from the white tree to our red wax stamp.
- **12-5-23** - Upgraded to MediaWiki version 1.39, which includes support for the Visual Editor.

### 2022 {#2022}

- **2-9-22** - Tolkien Gateway surpasses 100,000 visitors in a single day.
- **27-8-22** - Upgraded to MediaWiki version 1.35, introduced a new logo and a new skin designed to make articles easier to read on mobile devices.
- **18-8-22** - tolkien.wiki can now be used for shorter website addresses, an example is <a class="external free" href="https://tolkien.wiki/Gandalf" rel="noreferrer noopener" target="_blank">https://tolkien.wiki/Gandalf</a>

### 2012 {#2012}

- **12-12-12** - Doubled performance of server to accommodate increase in traffic. (over 20,000 unique visitors per day!).

### 2011 {#2011}

- **07-08-11** - With the installation of ConfirmEdit extension, anonymous users can now edit the wiki.
- **07-08-11** - The [Forum](https://tolkiengateway.net/wiki/Forums:Council) and Inputbox (now CreateBox) extensions have been fixed; new extensions BreadCrumbs (for easier navigation) and CategoryTree have been added.
- **07-08-11** - We have successfully upgraded to the new version of MediaWiki. New features include [Special:ComparePages](https://tolkiengateway.net/wiki/Special:ComparePages) and search suggestions.
- **06-08-11** - "Ithilien"/"Gateway to Ithilien" has been re-made to fix many bugs whilst running more smoothly with the new version of MediaWiki. The skin is now called "Mithilien" and is default.
- **05-06-11** - The email functions have been fixed meaning users are able to email one another and new users will receive confirmation emails.
- **02-06-11** - Now only autoconfirmed users (those who have a certain number of edits and have been registered for a certain amount of time) are able to create pages, upload images and move articles.
- **14-04-11** - The vast majority of downtime issues are resolved.
- **18-03-11** - Footer of Cavendish skin has been tweaked to consume much less space. Ithilien skin: categories now fit in the niche at the bottom; shading around the bottom has been removed (as it got in the way); page title has been moved up to be flush with the top of the navigation bar; page toolbar moved to fit properly in its niche.
- **16-03-11** - Tolkien Gateway reaches 9,000 articles! Well done, everyone!
- **04-02-11** - EmbedVideo, Editcount, ImageMap and Stringfunctions extensions have all been installed. Glitch in the user creation log has been fixed. Edit tools have been expanded with more buttons.
- **03-02-11** - [Mith](https://tolkiengateway.net/wiki/User:Mith) has started working on [Technical To-do](../T/Technical_To-do.md): re-enabling site-wide and user <a class="extiw" href="http://en.wikipedia.org/wiki/Cascading_Style_Sheets" title="wikipedia:Cascading Style Sheets">css</a> and <a class="extiw" href="http://en.wikipedia.org/wiki/JavaScript" title="wikipedia:JavaScript">js</a> (including highlighting references); restoring the edit buttons and CharInsert; removing the superfluous box around categories; fixing the navigation in the Ithilien skin; and providing a link to "My sandbox" in the Personal Toolbar.

### 2006 {#2006}

- **01-12-06** - Just in case you guys prefer Google Video to YouTube I've added a Google Video extension as well. Again, it's pretty simple, just insert something like &lt;googlevideo&gt;8119893978710705002&lt;/googlevideo&gt; where that long number is the ID found in the Google Video URL.
- **29-11-06** - I've gone ahead and added a YouTube extension until I can perfect our own video embedding scheme. To embed a video from YouTube just use the follow code &lt;youtube width="200" height="200"&gt;pISzxdEgDCU&lt;/youtube&gt; Where the jumble of letters is the video code on YouTube (found in the URL). We definitely don't want to abuse this and have tons of videos jammed on every page but I think it will help on some articles.
- **21-10-06** - Dang, just noticed we passed 1 million page views a while ago, congratulations!
- **20-10-06** - Had a bit of downtime this morning and quite a bit this evening but we think we've resolved the issue, sorry about that folks.
- **17-10-06** - Looks like the site had a small hiccup while I was sleeping and a few database tables were corrupted. The problem has been resolved and luckily the specific tables didn't hold all the content for the site. I'm going to switch from weekly to daily backups just in case it happens again.
- **16-10-06** - We've had the cavendish skin installed for a while now and I think it is overall better than the old Monobook skin so I've gone ahead and made it the default. You can of course always change your skin by clicking the Preferences link when you're logged in. This new skin will still undergo some changes as we definitely need to add more of a Tolkien-theme to it.
- **27-09-06** - We will be migrating to a new server on Sunday, no downtime is expected and the server will feature PHP5 which will allow us to get back to upgrading to the latest versions of MediaWiki, something we have been unable to do for the last few months due to only having PHP4. I'm hoping with the new server will also come TeTex/LaTeX/WikiTeX/TengTex which will allow us to dynamically generate the Tengwar like I promised.
- **27-09-06** - Moving the Community Portal to Tolkien Gateway:Updates as this seems a more proper place. The community portal definitely has its place but for now I think I'll just remove it.
- The Poem extension has now been added. To utilize the new extension simply encase your poem between &lt;poem&gt; and &lt;/poem&gt;. No more line breaks required after every line or using the pre tag.
- I'm proud to announce **Tolkien Gateway** has just passed 3,000 unique visitors in one day. We have all of the dedicated contributors to thank and at this point I think it's just a matter of time before people realize the potential of the site.
- Small skin changes. I've been playing around with the skin a lot of today so I'm sorry if anyone saw anything odd. I've added the A-Z links to the top center and removed them from the left where they were taking up way too much room. When we finalize some "Portal" pages such as the Gallery and maybe a Characters portal or something I'll throw those links on the left. Let me know what you guys think.
- thrasher7 has provided us with a new extension, the [Special:Editcount/TopEditors](https://tolkiengateway.net/wiki/Special:Editcount/TopEditors) extension which lists the top editors. Hopefully this will give us an extra incentive to keep editing. You can include your total edits in your user page by using {{Special:Editcount/Hyarion}} for example. Let the race to #1 begin!
- Kristine Kastle has written a <a class="external text" href="http://people.emich.edu/zgarrett/ColProject/3.html" rel="noreferrer noopener" target="_blank">critique of Tolkien Gateway</a> for her class. We received 1.5 out of 4 rings.
- The left navigational A-Z links have been fixed. Prior to the update they used Special:Allpages/A which would show a couple hundred pages starting with A but it might continue on through B and C. Now when you click A you will only see articlces starting with A.
- The upgrade to 1.6.3 is now complete! <a class="external text" href="http://www.mediawiki.org/wiki/Important_Release_Notes#MediaWiki_1.6.x" rel="noreferrer noopener" target="_blank">New Features</a>. Please let me know if you see any bugs that I might have missed.
- We have planned to upgrade from MediaWiki 1.5.4 to 1.6.3 today. This includes an added feature which forces people who edit anonymously and have a link in their edit, to type a random word. This should prevent pretty much all the vandalisms. If you find anything wrong after the upgrade, please let us know.
- If you haven't noticed we have converted our [Community Portal discussion](https://tolkiengateway.net/wiki/Tolkien_Gateway_talk:Community_Portal) to a forum-like atmosphere over on the [Council forums](https://tolkiengateway.net/wiki/Forums:Council) (a link is also present on the left navigation).
- It seems we have surpassed over 200,000 page views as well as over 200 registered users. Congratulations everyone.
- Over 500 articles and a day later I've now completed the redirect pages. Searching or even making a [Numenor](../../main/N/Númenor.md) link will redirect to the correct accented article.
- I'm still debating switching the main page to be simply a <a class="external text" href="http://tolkiengateway.net/search/" rel="noreferrer noopener" target="_blank">Search Page</a>. I like the idea of having a simplistic Google-like look, but I think the lack of news/information on the main page might not be liked. What do you guys think?
- I think I've decided to go through *every* article that has an accent and create a non-accented redirect to it. Search results do not display the correct results for something like "Numenor" since there are technically accents on the word. Creating the redirects will allow someone to search for "Numenor" and simply be redirected to the correct page. I've whined to the MediaWiki staff about creating an extension but it's just going to be too much work to do it like Google and even Wikipedia uses the redirect idea.
- Congratulations everyone, we have now surpassed 10,000 edits!
- I've altered the left navigation menu to display only alphabetical links. The old links were not fully completed even though the articles were written. I think this way people will be able to see how large our database is more efficiently. What do you guys think? Feel free to post on the discussion page.
- Unfortunately the last couple days we've had some MySQL issues which has caused some downtime. This is not viewed lightly and we've done everyting possible to prevent anymore downtime in the future. Sorry for the inconvenience.
- Congratulations to everyone who has worked on the Encyclopedia, we have now surpassed over 100,000 views.
