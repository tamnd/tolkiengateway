A **Redirect** is a page created so that the page title of the Redirect page forwards readers to a designated Target page.

It is created using the following syntax:

<pre>#REDIRECT [[Target page]]</pre>

It is also possible to add a section header to make a redirect to a specific section of the Target page using the following syntax:

<pre>#REDIRECT [[Target page#Section header]]</pre>

Please note that syntax is case sensitive.

Redirects for the different names of a subject should lead directly to the article, not to the "Other names" section. Note that Redirect pages can and sometimes must include categories, as well as a {{DEFAULTSORT}} tag to help its order within the categories.

## Example {#Example}

The Redirect page "<a class="external text" href="https://tolkiengateway.net/w/index.php?title=Ol%C3%B3rin&amp;redirect=no" rel="noreferrer noopener" target="_blank">Olórin</a>" redirects to [Gandalf](/wiki/Gandalf) using the following syntax:

<pre>#REDIRECT [[Gandalf]]</pre>

This Redirect page includes the "[Category:Maiar](/wiki/Category:Maiar)" and "[Category:Quenya names](/wiki/Category:Quenya_names)" because this is Gandalf's name as a [Maia](/wiki/Maia) and it is also a [Quenya](/wiki/Quenya) name; it does not require all the other categories applied to Galdalf like "[Category:Characters in The Hobbit](/wiki/Category:Characters_in_The_Hobbit)".
