The **Gnomic Letters** were a writing system created by [J.R.R. Tolkien](/wiki/J.R.R._Tolkien) while he worked in the [University of Leeds](/wiki/University_of_Leeds) between [1920](/wiki/1920)-[5](/wiki/1925 "1925"). It was conceived when Tolkien was first creating scripts and, like the [Gondolinic Runes](/wiki/Gondolinic_Runes), this script was never used thereafter. It is remarkable that it included a lower case system.

The letters were created as a script for the [Gnomish](/wiki/Gnomish) language, the only words transcribed being related to the language (*ilam naŋgóldaþon*).<sup id="cite_ref-1" class="reference"><a href="#cite_note-1">[1]</a></sup>
