## Definitions {#Definitions}

- **Top-level Category** - No actual location articles should be placed here, only lists relating to locations are acceptable.
- **Diffusing Category** - This category should already be diffused into subcategories, therefore articles should be placed in the relevant subcategories and not the diffusing category.
    - For example, the article <a class="mw-redirect mw-disambig" href="/wiki/Fangorn" title="Fangorn">Fangorn</a> should not be placed in [Category:Realms](/wiki/Category:Realms), instead it should be placed in the relevant subcategory, <a class="new" href="/w/index.php?title=Category:Entish_Realms&amp;action=edit&amp;redlink=1" title="Category:Entish Realms (page does not exist)">Category:Entish Realms</a>.
- **Partially-diffusing Category** - This category can contain both articles and subcategories. The subcategories do not diffuse the parent category completely, articles should be placed in either the subcategory or the parent category - not both.
    - For example, <a class="new" href="/w/index.php?title=Category:Shire&amp;action=edit&amp;redlink=1" title="Category:Shire (page does not exist)">Category:Shire</a> is a partially-diffusing category because it contains articles as well as more specific subcategories like [Category:Regions of the Shire](/wiki/Category:Regions_of_the_Shire).
- **End Category** - This category should only contain articles, and should not be diffused into subcategories.
