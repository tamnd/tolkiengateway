**NIMIR** is a [Mannish](/wiki/Mannish) (perhaps specifically [Adûnaic](/wiki/Ad%C3%BBnaic)) root base related to the [Elves](/wiki/Elves).

Adûnaic: <i><a class="new" href="/w/index.php?title=Nim%C3%AEr&amp;action=edit&amp;redlink=1" title="Nimîr (page does not exist)">Nimîr</a>, <a class="new" href="/w/index.php?title=Nimriy%C3%AA&amp;action=edit&amp;redlink=1" title="Nimriyê (page does not exist)">Nimriyê</a>, <a class="new" href="/w/index.php?title=Nimr%C3%BBn&amp;action=edit&amp;redlink=1" title="Nimrûn (page does not exist)">Nimrûn</a> <a class="new" href="/w/index.php?title=Nimruz%C3%AEr&amp;action=edit&amp;redlink=1" title="Nimruzîr (page does not exist)">Nimruzîr</a></i>

It's possible that it derived from the word <a class="new" href="/w/index.php?title=N%C3%B3min&amp;action=edit&amp;redlink=1" title="Nómin (page does not exist)">Nómin</a>, a [Taliska](/wiki/Taliska) name for the Elves.
