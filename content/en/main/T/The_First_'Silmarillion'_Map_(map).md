<br> **The First 'Silmarillion' Map** is a map of [Beleriand](/wiki/Beleriand) drawn by [J.R.R. Tolkien](/wiki/J.R.R._Tolkien) on single sheet (likely dating from c. 1926-30<sup id="cite_ref-1" class="reference"><a href="#cite_note-1">[note 1]</a></sup>), with "two supplementary sheets, giving an Eastern and a Western extension to the main or central map".<sup id="cite_ref-2" class="reference"><a href="#cite_note-2">[1]</a></sup> The name [Thimbalt](/wiki/Thimbalt), which probably refers to another fortress such as Angband, only appears on this map. Thimbalt was struck out using a pencil on this map.<sup id="cite_ref-3" class="reference"><a href="#cite_note-3">[2]</a></sup>.
