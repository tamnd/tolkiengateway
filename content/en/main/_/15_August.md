## On Earth {#On_Earth}

- **[1953](/wiki/1953)** - [J.R.R. Tolkien](/wiki/J.R.R._Tolkien) writes [a letter to Ronald Eames](/wiki/Letter_to_Ronald_Eames "Letter to Ronald Eames").
- **[1955](/wiki/1955)** - [J.R.R. Tolkien](/wiki/J.R.R._Tolkien) writes [Letter 167](/wiki/Letter_167).
- **[1975](/wiki/1975)** - [Mythcon 6](/wiki/Mythcon_6) at <a class="extiw" href="http://en.wikipedia.org/wiki/Scripps_College" title="wikipedia:Scripps College">Scripps College</a> in <a class="extiw" href="http://en.wikipedia.org/wiki/Claremont,_California" title="wikipedia:Claremont, California">Claremont</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/California" title="wikipedia:California">California</a>.
- **[1976](/wiki/1976)** - [Mythcon 7](/wiki/Mythcon_7) in <a class="extiw" href="http://en.wikipedia.org/wiki/Sacramento,_California" title="wikipedia:Sacramento, California">Sacramento</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/California" title="wikipedia:California">California</a>.
- **[1982](/wiki/1982)** - [Mythcon 13](/wiki/Mythcon_13) at <a class="extiw" href="http://en.wikipedia.org/wiki/Chapman_University" title="wikipedia:Chapman University">Chapman College</a> in <a class="extiw" href="http://en.wikipedia.org/wiki/Orange,_California" title="wikipedia:Orange, California">Orange</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/California" title="wikipedia:California">California</a>.
- **[1983](/wiki/1983)** - [Mythcon 14](/wiki/Mythcon_14) at <a class="extiw" href="http://en.wikipedia.org/wiki/Scripps_College" title="wikipedia:Scripps College">Scripps College</a> in <a class="extiw" href="http://en.wikipedia.org/wiki/Claremont,_California" title="wikipedia:Claremont, California">Claremont</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/California" title="wikipedia:California">California</a>.
- **[2005](/wiki/2005)** - [The Tolkien Society](/wiki/The_Tolkien_Society)'s [Tolkien 2005](/wiki/Tolkien_2005) conference in <a class="extiw" href="http://en.wikipedia.org/wiki/Birmingham" title="wikipedia:Birmingham">Birmingham</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/England" title="wikipedia:England">England</a>.
- **[2008](/wiki/2008)** - [Mythcon 39](/wiki/Mythcon_39) at <a class="extiw" href="http://en.wikipedia.org/wiki/Central_Connecticut_State_University" title="wikipedia:Central Connecticut State University">Central Connecticut State University</a> in <a class="extiw" href="http://en.wikipedia.org/wiki/New_Britain,_Connecticut" title="wikipedia:New Britain, Connecticut">New Britain</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/Connecticut" title="wikipedia:Connecticut">Connecticut</a>.
- **[2010](/wiki/2010)** - "[Edge of the Wild](</wiki/Edge_of_the_Wild_(Tolkien_art_exhibit)> "Edge of the Wild (Tolkien art exhibit)")", Tolkien art exhibition in <a class="extiw" href="http://en.wikipedia.org/wiki/Moreton-in-Marsh" title="wikipedia:Moreton-in-Marsh">Moreton-in-Marsh</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/England" title="wikipedia:England">England</a>.
- **[2023](/wiki/2023)** - *[Tolkien Calendar 2024](/wiki/Tolkien_Calendar_2024)* is published.
