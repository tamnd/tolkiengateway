- **[1997](/wiki/1997)** - [Mythcon 28](/wiki/Mythcon_28) at <a class="extiw" href="http://en.wikipedia.org/wiki/Pepperdine_University" title="wikipedia:Pepperdine University">Pepperdine University</a> in <a class="extiw" href="http://en.wikipedia.org/wiki/Malibu,_California" title="wikipedia:Malibu, California">Malibu</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/California" title="wikipedia:California">California</a>.
- **[2005](/wiki/2005)** - [The Tolkien Society](/wiki/The_Tolkien_Society)'s [Tolkien 2005](/wiki/Tolkien_2005) conference in <a class="extiw" href="http://en.wikipedia.org/wiki/Birmingham" title="wikipedia:Birmingham">Birmingham</a>, <a class="extiw" href="http://en.wikipedia.org/wiki/England" title="wikipedia:England">England</a>.
- **[2007](/wiki/2007)** - <a class="external text" href="http://omentielva.com/" rel="noreferrer noopener" target="_blank">Omentielva Tatya</a> - 2nd International Conference on [Tolkien](/wiki/J.R.R._Tolkien "J.R.R. - **[2013](/wiki/2013)** - [Omentielva Lempea](/wiki/Omentielva "Omentielva") - 5th International Conference on [Tolkien](/wiki/J.R.R._Tolkien "J.R.R. Tolkien")'s Invented Languages in Helsinki, Finland.
