<i><b>-enca</b></i> (from root [NEK](/wiki/NEK)) is a [Quenya](/wiki/Quenya) suffix meaning "without, -less".<sup id="cite_ref-1" class="reference"><a href="#cite_note-1">[1]</a></sup>

## Examples {#Examples}

There is no canonical word with this suffix, but [Helge Fauskanger](/wiki/Helge_Fauskanger) created a [neologism](/wiki/Neo-Quenya "Neo-Quenya") that can be used as an example: *nostarenca* ("parent-less, orphaned").<sup id="cite_ref-2" class="reference"><a href="#cite_note-2">[2]</a></sup> <span></span>
