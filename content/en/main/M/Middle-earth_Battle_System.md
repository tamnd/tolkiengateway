**Middle-earth Battle System** was a miniature battle game that was in development by [Iron Crown Enterprises](/wiki/Iron_Crown_Enterprises) in [1998](/wiki/1998). The game was to be based on ICE's <a class="extiw" href="http://en.wikipedia.org/wiki/Silent_Death" title="wikipedia:Silent Death">Silent Death</a> miniatures game. The project was led by Tim Goodlett.<sup id="cite_ref-1" class="reference"><a href="#cite_note-1">[1]</a></sup> The game would have featured 28mm scale miniatures.<sup id="cite_ref-2" class="reference"><a href="#cite_note-2">[2]</a></sup> It ultimately never made it into production.

The game was shown at <a class="extiw" href="http://en.wikipedia.org/wiki/PrezCon" title="wikipedia:PrezCon">PrezCon</a> 1998.<sup id="cite_ref-3" class="reference"><a href="#cite_note-3">[3]</a></sup> <span></span>
